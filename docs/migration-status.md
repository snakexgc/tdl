# AUTOSAR 架构变更与验收状态

更新：2026-09-19。记录当前工作区（含未提交文件），不是已发布版本。原有三次未推送提交保留。用户随后授权使用项目 `.tdl` 中的已登录账号进行保守测试，已完成下述串行实测；原会话文件及部署配置保持不变。

正常启动已默认进入组件配置和 RTE 装配路径；当前目录覆盖 18 个业务组件。现有 `app/` 协议及兼容适配器仍保留，不能把组件数量或静态检查等同于清除全部旧代码、AUTOSAR 标准认证或真实环境验收完成。

## 用户需求对应实现

| 要求 | 当前实现 |
| --- | --- |
| 架构继续转向 AUTOSAR | SWC/端口/RTE/BSW 分层；默认一次性配置导入；Manifest 声明业务配置、页面、命令、端口；策略宿主按实际依赖增量装配 |
| 尽量热更新 | 下载模式、目录、过滤/命名、表情、规则、并发、队列/监控、HTTP 链接参数原地更新；连接/监听参数自动协调相关服务，少量启动资源需要进程重启 |
| WebUI 通信 | HTTP 命令/快照 + 同源鉴权 WS；按主题共享采样、变化推送、断线重连和 HTTP 兜底；移除旧前端心跳轮询 |
| 模块页面配置 | Manifest.Settings 声明配置范围，公共组件表单；信息/配置标签保留草稿、暂停无用订阅；160ms 动画及减少动态效果支持 |
| aria2 与 HTTP 解耦 | 移除监听器对 HTTP/aria2 的错误生命周期依赖；执行器按提交动态解析；本地目录独立，不再读取远程 aria2 目录 |
| 模式切换同步 | status 推送触发管理页切换；销毁旧 AriaNg iframe、切换本地订阅，拦截过期异步结果；已准备任务保持执行器快照 |
| 下载优先 | 字节流继续直接流式传输、使用原配额/背压；统计集中采样；aria2 并发原地 RPC 更新，DC 连接池等正在执行的 RPC 完成后释放旧池 |
| 分组转发 | 独立 forward.rules SWC；当前账号聊天及归档目录；搜索/分类多选，多规则、多目标、复制/排序；环路校验、类型化 ID、各目标独立持久化及去重 |

设计决策、规则语义和更新边界见 [架构说明](autosar-runtime.md)。字段参考见 [生成配置文档](configuration.md)，默认导入和回退见 [迁移说明](config-migration.md)。

## 回归证据

- RTE：依赖顺序、停止失败保留提供者、重试停止、保持无关实例、可选端口重新绑定，以及已停用组件重新启用。
- 生产装配：常驻策略开关保持账号/无关端口实例，旧消费者通过动态端口感知停用和恢复；本地下载器单独启停不阻止 aria2 模式。
- 下载：准备与提交之间切换模式保留原执行器/目录；不创建远程路径；只有明确拒绝才允许降级；既有 Range、并行分片、慢写入、重试和内容逐字节一致性回归保留。
- 并发：DC 扩容时旧 RPC 不被关闭，已有客户端句柄使用新容量；aria2 不重启即可更新并发参数、链接归属与保留时间，远程目录变更不重建传输服务。
- 转发：多目标扇出、重复目标优先级、环路、配置失败保留旧策略、并发读写、同数字不同 peer 类型、相册和持久化重放去重；默认目标不可解析不阻塞显式规则。
- 聊天目录：分页及归档读取、类型分类、访问哈希落在账号缓存、DTO 不暴露访问哈希、缓存失败拒绝不完整列表。
- WS：未登录拒绝、跨源拒绝、配置模式推送、撤销会话关闭已建立连接。统计采样合并多个观察者。
- 前端 Node：声明式路由；单连接多主题、退避与 HTTP 兜底、过期 socket 消息忽略；标签生命周期、配置范围和草稿保留；局域网 HTTP 下规则创建/复制及 @用户名搜索。
- 默认导入：账号目录隔离、保留旧本地目录、重复启动不覆盖组件编辑、识别不完整导入。

## 保留边界

`app/watch` 的 Telegram 媒体恢复、`app/bot` 的旧消息格式化、`app/webui` 的旧 URL/处理器适配仍存在。业务组件已经有各自配置和 RTE 宿主，但进一步缩减这些兼容编排与存储适配属于后续收敛工作，不能宣称“旧架构代码全部消失”。涉及监听订阅和转发执行宿主的启停仍协调必要连接消费者；本地下载、常驻策略及 HTTP/aria2 已进一步隔离。

多账号并行不是本次实现范围。真实下载内容已校验；吞吐压测、重新登录/切换、aria2 网络故障恢复、受保护媒体转发及发布包运行仍未实测。真实账号没有进行并发测试。自动规则不追溯历史消息，不能提供跨网络故障的严格 exactly-once；队列历史清理后的永久去重不在当前保证范围。

历史记录见 [旧状态表](history/migration-status-before-2026-09-19.md)。
